# Programmable

Programmable is a platform for launching coins and applications on Uniswap v4. Creators configure coins with reusable modules or build projects with their own contracts. The public interfaces cover launch preparation, wallet handoff, onchain provenance and indexing.

[Open Programmable](https://programmable.market) · [Explore coins](https://programmable.market/explore/robinhood) · [Read the docs](https://programmable.market/docs)

## Build with Programmable

| Task | Starting point |
| --- | --- |
| Launch a coin with a bonding curve and optional modules | [Module Mode](https://programmable.market/launch/modules) |
| Launch your own token and hook contracts | [Custom Launch quickstart](https://programmable.market/docs/developers/custom-launch-quickstart) |
| Publish reusable modules | [Module contribution guide](https://programmable.market/developer-reference/module-mode) |
| Integrate launches into a terminal, explorer or wallet | [Indexing guide](https://programmable.market/docs/developers) |
| Read fees, revenue allocation and V4 tokenomics | [Product documentation](https://programmable.market/docs) |

On Robinhood Chain, Custom V4 supports separate token and hook contracts, while MultiRole V2 supports a shared token/hook contract under its published profile. The API prepares the exact transaction; the controller wallet reviews and signs it. Indexing verifies each launch source independently from market data and trading support.
